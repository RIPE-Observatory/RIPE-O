Authorc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#Author

A ripe:Author is a prov:Person and foaf:Person representing a person associated with an assessment-relevant resource represented in a ripe:ResearchIntegrityAssessment. Such resources may include works and other pieces of information, such as peer comments. The author of a journal article or the person named as responsible for a peer comment are examples of ripe:Author.
has super-classes
Person c, Person c
is in range of
concerns op

Automated agentc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#AutomatedAgent

A ripe:AutomatedAgent is a prov:SoftwareAgent representing a software agent that participates in a ripe:ResearchIntegrityAssessment by gathering evidence, deriving assessment-relevant information, or producing initial outcomes. Software that can perform ripe:EvidenceAggregation and produce ripe:IntegrityAssessmentHypothesis instances without human intervention is modelled as a ripe:AutomatedAgent.
has super-classes
Software Agent c

Correction noticec back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#CorrectionNotice

A ripe:CorrectionNotice is a fabio:Correction and ripe:IntegrityAssessmentEvidence representing a formal correction notice about a work and used as evidence in a ripe:ResearchIntegrityAssessment. For example, an erratum correcting a published article is a ripe:CorrectionNotice.
has super-classes
Correction c, Integrity assessment evidence c

Evidence aggregationc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#EvidenceAggregation

A ripe:EvidenceAggregation is a prov:Activity representing the aggregation of evidence and source records used in a ripe:ResearchIntegrityAssessment. It provides provenance for the evidence collected for one ripe:ResearchIntegrityAssessment. Retrieval of registry records and publication notices for a research integrity assessment is one such activity.
has super-classes
Activity c

Expression of concernc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#ExpressionOfConcern

A ripe:ExpressionOfConcern is a fabio:Comment and ripe:IntegrityAssessmentEvidence representing a formal journal or publisher notice that raises concerns about a work and is used as evidence in a ripe:ResearchIntegrityAssessment. For example, a publisher notice questioning the reliability of a published article is an expression of concern.
has super-classes
Comment c, Integrity assessment evidence c

Human reviewerc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#HumanReviewer

A ripe:HumanReviewer is a prov:Person and foaf:Person representing a human agent who participates in a ripe:ResearchIntegrityAssessment by evaluating evidence and recording ripe:IntegrityAssessmentHypothesis instances. A systematic reviewer investigating research integrity of a study is a ripe:HumanReviewer.
has super-classes
Person c, Person c

Integrity assessment evidencec back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#IntegrityAssessmentEvidence

A ripe:IntegrityAssessmentEvidence is a tido:Evidence item used to support, challenge, or contextualise a ripe:ResearchIntegrityAssessment. Publication metadata, registry evidence, study-design evidence, publication notices, and peer comments used in an integrity assessment are examples of ripe:IntegrityAssessmentEvidence.
has super-classes
Evidence c
has sub-classes
Correction notice c, Expression of concern c, Peer comment c, Publication details c, Registry evidence c, Retraction notice c, Study design evidence c
is in domain of
concerns op, retraction watch record identifier dp

Integrity assessment hypothesisc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#IntegrityAssessmentHypothesis

A ripe:IntegrityAssessmentHypothesis is a tido:Hypothesis that records an automated or human-reviewed answer to a ripe:IntegrityAssessmentQuestion. For example, a reviewer or automated agent may produce a hypothesis that a study has no concerns, some concerns, or serious concerns.
has super-classes
Hypothesis c
is in domain of
result outcome dp

Integrity assessment questionc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#IntegrityAssessmentQuestion

A ripe:IntegrityAssessmentQuestion is a tido:RQ and prov:Entity representing one specific integrity-related question investigated within a ripe:ResearchIntegrityAssessment. It is answered by one or more ripe:IntegrityAssessmentHypothesis instances via tido:answers. An example of a ripe:IntegrityAssessmentQuestion is a question asking whether a ripe:Work has an associated retraction.
has super-classes
Entity c, R Q c
has sub-classes
Overall integrity assessment question c

Overall integrity assessment questionc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#OverallIntegrityAssessmentQuestion

A ripe:OverallIntegrityAssessmentQuestion is a ripe:IntegrityAssessmentQuestion representing the overall integrity question investigated for a ripe:Work within a ripe:ResearchIntegrityAssessment. It is answered by one or more ripe:IntegrityAssessmentHypothesis instances that synthesise the component integrity assessment questions and their corresponding hypotheses.
has super-classes
Integrity assessment question c

Peer commentc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#PeerComment

A ripe:PeerComment is a fabio:Comment and ripe:IntegrityAssessmentEvidence representing a post-publication comment from the research community about a work and used as evidence in a ripe:ResearchIntegrityAssessment. For example, a PubPeer comment discussing methodological concerns is a ripe:PeerComment.
has super-classes
Comment c, Integrity assessment evidence c

Publication detailsc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#PublicationDetails

A ripe:PublicationDetails is a fabio:BibliographicMetadata and ripe:IntegrityAssessmentEvidence representing bibliographic metadata describing a work. It may record values such as title, publication venue, publisher, identifiers, and publication date. A record containing title, journal, publisher, and publication date for an article is one such instance.
has super-classes
Bibliographic Metadata c, Integrity assessment evidence c

Registry evidencec back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#RegistryEvidence

A ripe:RegistryEvidence is a ripe:IntegrityAssessmentEvidence representing information recorded in a registry about a registered study or clinical trial. It may record values such as the registry identifier, registration date, registry name, registry link, and the associated registration assessment rationale. A ClinicalTrials.gov or WHO ICTRP entry associated with a clinical trial publication is one such instance.
has super-classes
Integrity assessment evidence c
is in domain of
is prospective dp, registration assessment rationale dp, registration date dp, registration identifier dp, registration link dp, registry name dp

Research integrity assessmentc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#ResearchIntegrityAssessment

A ripe:ResearchIntegrityAssessment represents one integrity assessment of a work. It brings together the ripe:Work that is the subject of the assessment, the ripe:IntegrityAssessmentQuestion instances investigated, the ripe:IntegrityAssessmentHypothesis instances answering those questions, the ripe:IntegrityAssessmentEvidence instances supporting them, and the activities that generated or reviewed those outcomes. An assessment of a single published clinical trial report is one such instance.
has super-classes
Case c
is in domain of
assesses op

Retraction noticec back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#RetractionNotice

A ripe:RetractionNotice is a fabio:RetractionNotice and ripe:IntegrityAssessmentEvidence representing a formal retraction notice used as evidence in a ripe:ResearchIntegrityAssessment. For example, a journal-issued retraction notice for an article is a ripe:RetractionNotice.
has super-classes
Integrity assessment evidence c, Retraction Notice c

Study design evidencec back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#StudyDesignEvidence

A ripe:StudyDesignEvidence is a ripe:IntegrityAssessmentEvidence representing information about the design and timeline of a registered study or clinical trial. It may record values such as recruitment start, recruitment end, and study end dates, together with rationales supporting those assigned values. A record describing the recruitment and completion timeline of a clinical study is one such instance.
has super-classes
Integrity assessment evidence c
is in domain of
recruitment end date dp, recruitment end date extraction rationale dp, recruitment start date dp, recruitment start date extraction rationale dp, study end date dp, study end date extraction rationale dp

Workc back to ToC or Class ToC

IRI: https://w3id.org/ripe/ripe-o#Work

A ripe:Work is a fabio:Work and prov:Entity representing a work relevant to a ripe:ResearchIntegrityAssessment. It may be the subject of an assessment, a cited publication, or another work connected to assessment evidence, such as an article associated with a publication notice. For example, an article, a cited paper, or an article retracted by a notice may be represented as a ripe:Work.
has super-classes
Entity c, Work c
is in range of
assesses op, concerns op

IRI: https://w3id.org/ripe/ripe-o#assesses

Research integrity assessment c
has range

concernsop back to ToC or Object Property ToC

IRI: https://w3id.org/ripe/ripe-o#concerns

Relates a ripe:IntegrityAssessmentEvidence instance to the ripe:Work or ripe:Author to which the evidence applies. This property is used when an evidence item bears on a work, an author associated with that work, or both. For example, publication metadata, registry evidence, and peer comments may relate to a ripe:Work via ripe:concerns, while a publication notice may also relate to one or more ripe:Author instances via ripe:concerns.
has domain
Integrity assessment evidence c
has range
Author c or Work c
